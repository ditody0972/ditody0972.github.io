prominence-backup

prominence-backup is a personal, single-user tool used by its developer to upload backup archives of a private game server to the developer's own Google Drive. It uses the Google Drive API with the drive.file scope only, so it can access only the files it creates itself. It is not offered to other users.

prominence-backup은 개발자 본인이 운영하는 비공개 게임 서버의 백업 파일을 본인의 Google 드라이브에 올리는 개인용 도구입니다. 이 앱이 만든 파일에만 접근하는 drive.file 범위만 사용하며, 다른 사용자에게 제공되지 않습니다.
